# Anime neutral face base v3

- Final UI asset: `anime-neutral-v3.png` (RGBA)
- Chroma-key source: `anime-neutral-v3-keyed.png`
- Canvas: 2048 × 2048 pixels
- Registration: centered, front-facing head only; no neck or facial-feature layers
- Status: illustrator-approved production draft, not yet rig-ready

The asset was generated with the built-in image-generation tool as a Japanese anime-style modular face base. The source used a flat green chroma background; the final PNG was processed with soft matte, despill, a one-pixel edge contraction, and normalization to the fixed canvas.

Before producing compatible eyes, mouths, or hair, define and record fixed eye-line, mouth-line, face center, and skull-boundary anchors against this exact canvas.
