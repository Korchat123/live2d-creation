# Generated test avatar v1

This opt-in Studio test avatar was generated from the user's supplied character
description on 2026-07-29. Its PNG layers were chroma-keyed locally to alpha.
The active preview uses a white-eye base and a separate pupil layer to exercise
gaze movement. It is experimental source artwork, not an approved first-party
release avatar.

Open Studio with `?avatar=generated` to preview it without replacing the
minimal fixture.
