# Private avatar-kit catalog v1

These are full-canvas `896x1152` RGBA authoring assets for the private
`standard-front-v1` Studio catalog.

The first admitted slice redraws three feminine face silhouettes selected from
the user-supplied Gemini PDF. The PDF JPEG cells are reference material only;
they are not shipped as motion textures. The admitted files were redrawn with
Codex built-in image generation, chroma-matted locally, normalized to canonical
face anchors, and visually reviewed.

Do not publish or release this directory while `provenance.json` reports
`releaseEligible: false`.
